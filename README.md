# Lumora Keyboard

## Android beta 0.4.0

[Download APK](https://raw.githubusercontent.com/vihangabhishek/lumora-keyboard-releases/main/Lumora-Keyboard-0.4.0.apk) · Android 7.0 or later

Blue glass keyboard with English, Sinhala, Singlish and Tamil layouts. New rounded settings cards, height and text-size controls, sound and vibration options, high contrast, spacebar cursor movement, and typing/deletion fixes.

No Google services, ads or analytics. Typing stays on your device. About → Updates checks this repository; Android asks you to confirm installation.

**Upgrading from 0.1/0.2:** those debug builds used lost, different signing keys. Uninstall the old app once before installing 0.4. This deletes local settings and photo themes. Subsequent releases must use the same 0.4 signing identity.

This is a beta: Sinhala/Tamil layouts and transliteration are basic; full prediction and handwriting are not included. Automated unit/lint checks and Android 10 emulator typing/update-verification tests passed. Physical-device and future signed-upgrade testing remain necessary.
